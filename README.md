# FP3級 最短合格コーチ

知識ゼロの初心者が、日本FP協会の3級FP技能検定に向けて、1日60分・週5日で学習するためのスマホ対応Webツールです。

## 開き方

このフォルダで次を実行します。

```bash
python3 -m http.server 4173
```

Macで開く場合:

```text
http://127.0.0.1:4173/
```

スマホで開く場合は、スマホとMacを同じWi-Fiにつなぎ、MacのローカルIPアドレスを使って次の形で開きます。

```text
http://MacのIPアドレス:4173/
```

## 外出先で使う方法

このツールはPWA対応済みです。一度スマホで開いてホーム画面に追加すると、学習画面、基礎講義、ミニテスト、暗記カードはオフラインでも開けます。

### iPhone

1. Safariでツールを開く
2. 共有ボタンを押す
3. 「ホーム画面に追加」を選ぶ
4. ホーム画面の「FP3コーチ」から起動する

### Android

1. Chromeでツールを開く
2. メニューを押す
3. 「アプリをインストール」または「ホーム画面に追加」を選ぶ
4. ホーム画面の「FP3コーチ」から起動する

### 外出先から初回アクセスするには

`127.0.0.1` や `MacのIPアドレス` は自宅Wi-Fi内だけで使えるアドレスです。外出先で初回アクセスしたい場合は、次のどちらかが必要です。

- GitHub Pages、Netlify、Cloudflare Pagesなどに置く
- 自宅Macを外部公開する

おすすめはGitHub Pagesなどの静的ホスティングです。ファイルはHTML、CSS、JavaScriptだけなので、そのまま公開できます。

## 入っている機能

- 今日の60分メニュー
- 6分野の基礎知識ロードマップ
- 30〜50分で読める分野別の基礎講義
- 頻出論点、数字・公式、例題、基礎ドリル
- 分野ごとの確認問題
- 8週間の最短合格プラン
- FP3級ミニテスト10問
- 採点と誤答ノート自動追加
- 手入力の誤答ノート
- 頻出論点の暗記カード
- ブラウザ内保存による進捗管理
- ホーム画面追加とオフライン利用

## 注意

年金、税金、NISA、相続、不動産税制など法改正が関係する論点は、学習前に日本FP協会などの公式情報で最新情報を確認してください。

## 基礎パートの使い方

知識ゼロの場合は、いきなり問題だけを解くより、各分野の基礎講義を1日1分野ずつ読みます。

```text
基礎講義30分 → 同じ分野の問題10〜15問 → 誤答ノート → 翌日復習
```

6分野を1周したら、2周目からは過去問演習の比率を増やします。
